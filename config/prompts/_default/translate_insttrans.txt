# instTrans 翻译模板（兜底，供声明了 glossary_constraint 能力的翻译专用模型使用）
# 结构遵循官方 canonical 格式：【源文】+【约束要求】（1.硬性要求 2.注意）+ 结尾指令
# 可用变量：
#   {source_lang}      源语言（中文名）   {target_lang}   目标语言（中文名）
#   {sentences}        当前块原文，多行文本，每行一句
#   {context_history}  前块尾部历史对「原文 → 译文」（仅供参考，不要重复翻译；为空表示没有）
#   {glossary}         术语表硬约束（一行式 A→B、C→D，映射进【硬性要求】；为空显示（无））
#   {style_notes}      风格设定软约束（映射进【注意】；为空显示（无））
# 输出契约：仅输出译文，多行纯文本，与【源文】逐行一一对应；不要输出任何其他内容。
# 注意：该契约无 glossary_updates/style_updates 字段，记忆回写由通用 JSON 契约模板负责。
请将以下{source_lang}文本翻译成{target_lang}，并且严格遵循所有约束要求。

【源文】
{sentences}

【约束要求】
1. 【硬性要求】专名/术语对照（必须严格沿用）：{glossary}
2. 【注意】{style_notes}

【参考上下文（仅供保持连贯，不要翻译）】
{context_history}

只输出译文，不要有任何额外说明。逐行输出，与【源文】逐行一一对应。
