## 0. 角色指令（Prompt 开头直接使用）

> 你是一名资深桌面应用前端工程师。请按以下规格实现一个 Windows 桌面悬浮字幕窗（PyQt6）。该窗口是「实时语音识别翻译与语言学习工具」的主交互界面，核心特征是：置顶半透明、可点击穿透、逐句滚动显示双语字幕、点击句子弹出语法学习卡、外观全部即时可调、翻译模型与语法分析模型以**可插拔槽位**形式呈现。所有数值均可配置化，UI 文案抽离为资源文件。以下为完整规格，请严格按组件树和交互清单实现，不要自行增删功能区。

## 1. 窗口整体形态

- **无边框置顶悬浮窗**（`FramelessWindowHint | WindowStaysOnTopHint | Tool`），圆角 8px，整体半透明
- 默认尺寸 720×480，最小 400×240，可拖拽右下角手柄缩放（手柄常驻可见，非仅 hover）
- 支持整体拖拽移动（按住顶部工具栏空白处）
- 三个层级开关以工具栏 checkbox 呈现，状态实时可见：**鼠标穿透**（开启后窗口不响应鼠标，仅显示）、**始终置顶**、**自动滚动**（新句到达时滚到底部；用户上翻时自动暂停并显示「回到底部」浮动按钮）
- 关闭/最小化行为：主悬浮窗关闭 = 退出实时会话（弹确认）；可最小化到任务栏

## 2. 布局解剖（自上而下四个区域）

```
┌──────────────────────────────────────────────────────────┐
│ A. 顶部工具栏                                              │
│  ≡应用名   □鼠标穿透 ☑始终置顶 ☑自动滚动 □紧凑模式          │
│            [字幕] [运行/暂停] [清除] [设置] [退出]          │
├──────────────────────────────────────────────────────────┤
│ B. 档案与模型槽位栏（可在设置中隐藏）                         │
│  档案: [日语 ja→zh ▾]  翻译: [Index-Translate-2B·本地 ▾]   │
│        语法: [云端·deepseek-chat ▾]                        │
├──────────────────────────────────────────────────────────┤
│ C. 状态监控条（单行，等宽字体，可在设置中隐藏）                │
│  RMS ▓░░░ 12% VAD ▓▓░░ 45% | SenseVoice Small [cuda:0]    │
│  CPU 18% RAM 2.1GB GPU 2.4GB | llama.cpp:8080 ● | ASR 29  │
├──────────────────────────────────────────────────────────┤
│ D. 字幕滚动区（主体，占满剩余空间）                           │
│  [21:23:47] [en] He's always with us.        ASR 853ms    │
│  > 他一直与我们同在。                            TL 1926ms  │
│  [21:23:52] [en] I'm sorry, I was so nervous.             │
│  > 对不起，我太紧张了。                                       │
│  [error: timed out]                        （错误行样式）    │
└──────────────────────────────────────────────────────────┘
```

### A. 顶部工具栏
- 左侧：菜单按钮（≡）＋应用名；中部：四个即时开关（鼠标穿透/始终置顶/自动滚动/紧凑模式）；右侧按钮组：字幕（开关字幕区）、运行/暂停（切换识别状态，按钮文案随状态变化）、清除（清空滚动区，确认后执行）、设置、退出
- 全部按钮带 tooltip；工具栏高度 36px，紧凑模式下收窄为 28px 仅保留图标

### B. 档案与模型槽位栏（对接《模型接入 Prompt》§1 槽位架构）

三个并排的**指示器＋下拉选择器**，实时反映 Provider Registry 与槽位绑定状态：

| 指示器 | 内容 | 行为 |
|---|---|---|
| **语言档案选择器** | 显示「显示名 源语言→目标语言」，选项来自 `config/languages/*.yaml` 扫描 | 切换即时生效：识别/翻译/语法卡全部切换到新档案；**若档案内覆盖了槽位绑定（《模型接入 Prompt》§2），两个槽位指示器同步刷新**；滚动区插入系统提示行「已切换到 日语档案」 |
| **翻译槽位指示器** | 显示当前绑定的 Provider（名称＋本地/云端标记，如「Index-Translate-2B·本地」）；未绑定时显示红色「未绑定」 | 下拉列出所有声明了 `translation` 能力的 Provider（能力过滤，见《模型接入 Prompt》§1.1）；**选择即换绑**（依赖槽位热替换引用，保存到配置并即时生效），换绑后滚动区插入系统提示行「翻译模型已切换为 ×××」；换绑进行中（本地模型加载中）指示器显示加载动画并禁点 |
| **语法槽位指示器** | 同上，显示语法分析槽位当前绑定；未绑定时显示灰色「未启用」 | 下拉仅列出声明了 `grammar` 能力的 Provider；含一个常驻首项「未启用」（即解绑，语法功能整体停用）；换绑交互同翻译槽 |

- 三个指示器均为**常驻可见的槽位状态入口**，不允许藏进深层菜单；紧凑模式下压缩为三个小图标（档案/翻译/语法），点击弹同样的下拉
- 本地 Provider 指示器带状态圆点：绿（运行中）/黄（启动加载中）/红（进程异常退出，点击圆点查看日志入口）
- 语言档案切换导致槽位被档案覆盖换绑时，指示器短暂高亮闪烁一次，提示用户绑定发生了变化

### C. 状态监控条
- 等宽字体 10px，单行显示：RMS 音量条、VAD 激活度条、ASR 后端与设备（如 `SenseVoice Small [cuda:0]` 或 `[cpu]`）、CPU/RAM/GPU（含显存）占用、ASR/翻译句数与平均耗时
- **新增：本地 Provider 进程段**——被托管的本地服务（如 `llama.cpp:8080 ●`）显示端口与状态圆点；无本地 Provider 时该段不显示
- 1s 刷新一次；GPU 显存超过预算（主 PRD §4.2，ASR＋本地翻译模型合计占用后保留量 < 2GB）时该项变橙告警，tooltip 给出「建议将翻译模型切换为 CPU 推理或云端 Provider」

### D. 字幕滚动区（核心）
- 每句为**一个句块（SentenceBlock）**，两行结构：
  - 原文行：`[HH:MM:SS] [语言标签] 原文`，右侧灰色小字显示 ASR 耗时
  - 译文行：以 `> ` 前缀开头，右侧灰色小字显示翻译耗时（TL xxms）；译文未返回时显示淡色「翻译中…」占位，返回后原地替换
- **三种状态样式**：原文行（主字体颜色）、译文行（次要字体颜色，可独立配置）、错误行（红色 `[error: ...]`，如超时/识别失败，不阻塞后续句子）
- 新句从底部插入，自动滚动到底（受「自动滚动」开关约束）
- 系统提示行（切换档案、槽位换绑、离线降级、连接恢复）以居中灰色斜体小字显示，与字幕句块视觉区分

## 3. 外观即时自定义

悬浮窗**自身内嵌快捷外观调节**，不需进入完整设置页：

- **触发方式**：右键滚动区弹出上下文菜单，含「外观设置…」；或工具栏设置按钮 → 外观分页
- **即时可调项**（调整即所见即所得，无需重启）：
  | 项目 | 控件 | 范围/说明 |
  |---|---|---|
  | 窗口尺寸 | 右下角拖拽手柄 | 400×240 ～ 无上限 |
  | 背景颜色 | 取色器＋预设色板（纯黑/深灰/深蓝/白色） | 任意 RGB |
  | 背景不透明度 | 滑块 | 20%–100%，实时预览 |
  | 原文字体/字号/颜色 | 字体下拉＋字号 spinner＋取色器 | 字号 12–32px |
  | 译文字体/字号/颜色 | 同上，独立于原文 | 译文可单独调小/调淡 |
  | 行间距 | 滑块 | 紧凑/标准/宽松三档快捷＋数值 |
- 所有外观参数持久化到配置文件，启动时恢复；提供「恢复默认外观」按钮
- 语言档案可保存各自的外观覆盖（如日语档案用更大字号方便看汉字注音）

## 4. 语法卡交互（对接 PRD FR-4）

- **触发**：鼠标悬停句块 → 句块背景高亮（透明度 +10%）＋ 光标变手型；**单击句块弹出语法卡**。仅当该句存在语法分析数据时可点击，否则句块无 hover 反馈
- **语法卡（GrammarCardPopup）**：无边框悬浮卡片，从被点击句块旁弹出（自动避让屏幕边缘），点击卡片外部或 Esc 关闭；同一时间只存在一张卡
- 卡片内容按语言档案声明的区块动态渲染（PRD §5.2），**日语档案默认渲染**：
  1. 句子原文＋译文（卡片头部）
  2. 句子结构划分：分句列表，每段原文下标注成分与说明
  3. 语法点列表：语法名、讲解、例句、JLPT 等级标签（彩色徽章 N5 绿 → N1 红）
  4. 词汇表：词、假名读音、词性、释义；每行右侧「＋生词本」按钮
- 卡片宽度固定 420px，内容超高时内部滚动；卡片样式继承悬浮窗字体设置，但背景不透明（保证可读性）
- 无分析数据的句子长按或右键 → 菜单提供「为此句生成语法分析」（即时调用语法槽位当前绑定的 Provider，走缓存）；**语法槽位未绑定时该菜单项置灰**，tooltip 提示「请先在设置中绑定语法分析模型」

## 5. 设置页结构（对接《模型接入 Prompt》§5）

设置按钮打开 SettingsDialog，分页结构：

| 分页 | 内容 |
|---|---|
| 外观 | §3 的全部外观项（与右键快捷面板同源） |
| **Provider 管理** | 已注册 Provider 列表：新增/编辑/删除（对应 config.yaml 的 `providers` 节）；每个条目含名称、类型（llama_cpp_server / openai_compatible / vllm）、base_url、api_key、model、能力勾选（translation / grammar / glossary_constraint）；「测试连接」按钮（云端发 ping 请求，本地拉起一次健康检查）；本地类型额外有 GGUF 文件选择器、下载入口（HF/ModelScope 双源）、server_args、显存预算 |
| **槽位绑定** | 翻译槽/语法槽的全局默认绑定（下拉按能力过滤，同 B 栏）；提示「语言档案内的槽位覆盖优先于此处」 |
| 音频 | 输入源（麦克风/loopback）、设备选择 |
| 常规 | 界面语言、输出目录、悬浮窗区域显隐（B 栏/C 栏开关） |

- 首次启动设置向导（setup_wizard）流程：①注册至少一个 Provider → ②为翻译槽、语法槽各选一个绑定（语法槽可跳过=未启用）→ ③进入主界面；向导每一步都有「测试连接」即时验证

## 6. 状态与降级提示

| 状态 | 表现 |
|---|---|
| 识别运行中 | 状态监控条正常刷新，运行按钮显示「暂停」 |
| 翻译槽位未绑定/不可用 | B 栏翻译指示器红色「未绑定」；译文行显示「（未配置翻译模型）」占位；识别流不受影响 |
| 语法槽位未绑定 | B 栏语法指示器灰色「未启用」；语法分析后台任务不排队、语法卡不弹、右键「生成语法分析」置灰；其余功能正常 |
| 本地 Provider 启动中 | 对应槽位指示器黄点＋加载动画，状态条进程段显示端口；加载期间该槽位请求排队而非报错；超时（默认 60s）未就绪转红点并插入系统错误行 |
| 换绑生效 | 指示器短暂高亮；滚动区插入系统提示行「××槽位已切换为 ×××」；进行中的旧请求跑完自然结束，UI 不做任何中断闪动 |
| 档案覆盖换绑 | 切换语言档案时若槽位绑定被档案覆盖，指示器闪烁一次提示 |
| 离线/云端 Provider 不可用 | 状态条插入黄色「云端不可用」标记；若翻译槽绑的是云端，译文行显示「（离线，未翻译）」占位；本地 Provider 不受离线影响 |
| ASR 超时/单句失败 | 红色错误行插入滚动区，不阻塞后续 |
| 显存超限 | 状态条 GPU 项橙色告警＋tooltip 提示建议（切 CPU 推理/换云端 Provider） |
| 鼠标穿透开启 | 工具栏淡出为仅 20% 透明度，hover 边缘时恢复显示以便关闭穿透 |

## 修订（2026-10-20）：手势分离与数据安全语义

实现时对原规格做如下统一修订，以此为准：

1. **单击/语法手势分离**：实时模式保留「单击有分析句块弹语法卡」；**回放模式单击任意句块只发 seek**（含无分析句），双击或右键菜单独立弹语法卡。任何一次手势不得同时触发 seek 与弹卡。
2. **档案切换 = 会话滚动**：运行中切换语言档案时，暂停接收新句 → 冲刷翻译块 → 排空语法任务 → 旧会话完整落盘 → 新档案重建翻译/记忆/语法/文档 → 新字幕视图插入「已切换档案」系统提示行。不把两种源语言混写进同一 `analysis.<lang>.json`。
3. **清空显示 ≠ 清空数据**：A 栏「清空显示」只清当前控件，不删除会话文档、滚动记忆或已落盘文件，且需确认；退出实时会话（关闭按钮/托盘退出）需单独确认。
4. **档案覆盖槽位时保持诚实**：档案固定槽位时，B 栏/设置页显示「档案覆盖」锁定标识并禁用全局改绑，不假报"已生效"。
5. **本地到本地换绑优先安全**：候选健康检查/启动在 worker 线程；旧代实例等在途租约排空后回收；GUI 只呈现 applying/draining/failed/ready，不等待网络或进程。
6. **回放暂停只控制播放器**，不改变会话文档；实时暂停停止接收新 ASR 句，在途翻译/语法自然完成，恢复时丢弃积压从当前音频继续。
