## 开发环境（WSL / Linux）

WSL 无 PortAudio 与 Windows 音频栈，mic/loopback 模块延迟导入、不参与测试；

```bash
uv venv --python 3.12 .venv && uv pip sync uv.lock
.venv/bin/python -m pytest tests/             # 单元测试（无需音频设备/GPU）
ASR2CLASS_E2E=1 .venv/bin/python -m pytest tests/test_pipeline_e2e.py   # 真实模型端到端
```

## 关键设计约定

- **代码零硬编码模型/服务商名**：全部 Provider 在 `config.yaml` 声明，测试 `test_no_hardcoded_provider_names` 强制约束（config 示例除外）。
- **i18n**：`config/locales/zh_CN.yaml` 与 `en.yaml` 的 key 集合必须一致（有测试）。
- **配置写回**：UIConfig 新增字段必须同步 `save_ui_config` 的写回映射（roundtrip 测试强制）。
- **脚本/批处理文件保持纯 ASCII**：Windows cmd 按系统 ANSI 代码页（中文系统 GBK）解析 .bat，UTF-8 中文会破坏解析（见 `启动.bat` 头部注释）。
- 需求与设计文档：`doc/实时语音翻译学习工具-需求文档.md`、`doc/20261014/`、`doc/20261015/`、`doc/20261019/`。
